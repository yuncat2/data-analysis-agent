# v6 — 方法选择 / 统计判断（2026-11-15）

## 这一版是什么

v5 的 39 道 **+ 3 道方法选择题** = 42 道。

新增题型考的不是"算得准不准"，而是"**该不该这么算**"——选错方法，数字就不同，蒙不过去。

| 题目 | 数据集 | 考点 | 标准答案（现算） |
|---|---|---|---|
| `method_stratify_tooth` | ToothGrowth | **混杂/分层**：整体 p=0.060 不显著，固定 dose 后显著 | `[0.0606, 0.00104]` + 必须提到 混杂/分层/剂量 |
| `method_skew_airq` | 北京 PM2.5 | **偏态**：均值 98.61 被长尾拉高，中位数 72 才代表典型水平 | `[72.0]` + 必须提到 中位数 **且** 偏态 |
| `method_anova_plant` | plantgrowth | **前提检验**：正态+方差齐 → ANOVA p=0.0159（Kruskal 会得 0.0184） | `[0.0159]` + 必须提到 ANOVA **且** 正态/方差齐 |

判据设计为「**数字 + 表述双条件**」：`expect_numbers` 全部命中（容差 0.001，能区分 ANOVA 与 Kruskal），
`expect_regex` 全部匹配（AND 语义，防止"提一句关键词就过"）。

## 结果：3/3 全过，而且答案质量超出要求

| 题目 | 步数 | token | 结果 |
|---|---|---|---|
| `method_stratify_tooth` | 4 | 11,652 | ✓ |
| `method_skew_airq` | 3 | 7,508 | ✓ |
| `method_anova_plant` | 4 | 9,001 | ✓ |

**先验证了"不是判据太松"**，逐条读了回答：

- 混杂题：报了 0.0604 和 0.00078 两个 p，明确写「剂量是强混杂因素」，还顺手报了 Levene p=0.275
- 偏态题：给了中位数 72.0，另外报了偏度 1.802、峰度 4.769、CV 0.933，**还做了稳健性检验**（剔除最高 1% 后均值变 3.98、中位数只变 1）
- ANOVA 题：F=4.846 / p=0.0159，三组 Shapiro（p=0.748/0.452/0.564）、Levene p=0.341、**Bartlett 交叉验证**、η²=0.264

## 结论：统计判断不是这个模型的瓶颈

**规则库（判断类规则）这个方向，价值不大。** 原因：

| 模型缺什么 | 需要规则库吗 |
|---|---|
| 知道**数据脏在哪**（汇总行、单位污染） | ✅ 需要 → 但已由 `load_data` 的质量提示 + 数据入口自动规范化解决 |
| 知道**该用什么方法**（检验选择、前提检查） | ❌ **不需要**，它本来就会 |

这解释了一个之前的谜团：**为什么数据质量提示有效（67%→100%），而判断类规则想不出增量**——
因为前者是"模型不知道的事实"，后者是"模型已经掌握的知识"。

> 一条可以写进 README 的判断：**给模型的提示应该补"它不可能知道的信息"，而不是"它应该会的知识"。**

## 规则库重新定位：从「判断规则」缩到「领域口径」

真正模型不可能知道、又会影响答案的是**数据集特定口径**，例如：

- 「ECB HICP 的 `value` 是同比通胀率，不是指数」
- 「世界银行 `iso3` 为空的行是收入分组/地区汇总」
- 「airquality 的 `pm2.5` 单位是 μg/m³，0 值多为仪器缺测」

`eval_data/<数据集>/meta.json` 是现成的挂载点，现在有 `name/zh/topic/source/license/rows/cols`，
**但没有口径说明字段**。如果要补，加一个 `caliber` 或 `notes`，由 `load_data` 顺手读同目录的 meta.json 注入即可。

## 这三道题的保留价值

即使当前模型全过，它们仍应留在评测集里：

1. 它们是**统计正确性的回归守卫**——以后改 prompt / 换模型时，能立刻发现"不再检查前提了"
2. 面试时能证明「我的 agent 在统计判断上达到专业水平，且我用可判定的方式验证过」

## 已知局限

- 3 道题不足以下**全局结论**。更难的判断（多重比较校正、配对 vs 非配对、交互作用）没测
- 沙箱只有 pandas/numpy/scipy，**没有 statsmodels**，所以两因素 ANOVA 这类题出不了。
  这条约束要写进出题规范，否则会出"算不出来"的题
