## 目录结构

```
产出\数据集\
  <dataset_id>\
    data.csv        原始数据（UTF-8 with BOM）
    meta.json       元数据：来源、许可、行数、缺失率、sha256
  数据集清单.csv    总表
  数据字典.csv      变量级说明（类型、缺失率、取值范围）
```

## 已知问题

1. **FRED 四个宏观序列未获取**（UNRATE、CPIAUCSL、GDPC1、FEDFUNDS）——该域名在本机不可达，请求 150 秒超时。已用 ECB 的调和 CPI 与政策利率替代，但缺少美国失业率与 GDP 序列。
2. **Eurostat 失业率接口返回 400**，未纳入。
3. **ECB 数据需忽略 TLS 校验**才能下载（本机缺中间证书），数据本身无问题，但复现时需注意。
4. **UCI 的 iris 与 wine 没有列名**（原始文件无表头），已按常见列名补上，wine 的列仍为 0–12 数字。
5. 各数据集时间范围、口径不一致，**不可直接横向拼接**；合并前须先做口径对齐与单位换算。

## 使用约定

- 每个数据集只能通过 `dataset_id` 引用，不要在文档里写路径。
- 任何派生数据（清洗后、聚合后）另存新文件，**不要覆盖 data.csv**。
- 引用时须同时标注 `source` 与 `license`。
